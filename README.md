# خرج‌سفر (SafarDanesh) – PWA

برنامه‌ی تقسیم هزینه و تسویه حساب سفر؛ فارسی/انگلیسی، قابل نصب روی گوشی.

## انتشار روی GitHub Pages
1. یک مخزن (repository) جدید بسازید، مثلاً `safardanesh`.
2. همه‌ی فایل‌های این پوشه را با همان ساختار آپلود کنید:
   `index.html`، `manifest.webmanifest`، `sw.js` و پوشه‌ی `icons/`.
3. در مخزن: **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` و پوشه‌ی `/ (root)` → Save
4. بعد از یکی دو دقیقه آدرس `https://USERNAME.github.io/safardanesh/` فعال می‌شود.

## نصب روی گوشی
- **اندروید (Chrome):** آدرس را باز کنید؛ کادر «نصب خرج‌سفر روی گوشی» نشان داده می‌شود → «نصب».
  اگر نیامد: منوی ⋮ ← Install app.
- **آیفون (Safari):** دکمه‌ی Share ← Add to Home Screen.

## نکته‌ها
- بار اول باید اینترنت وصل باشد؛ بعد از آن برنامه آفلاین هم باز می‌شود.
- اطلاعات فقط داخل مرورگر همان گوشی ذخیره می‌شود. از تب «پشتیبان» خروجی JSON بگیرید.
- بعد از هر تغییر در فایل‌ها، عدد `V` را در `sw.js` عوض کنید (مثلاً `v2`) تا نسخه‌ی جدید روی گوشی‌ها جایگزین شود.
